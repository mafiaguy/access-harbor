What you’ll learn

  • Describe the main parts of a computer and what they do.
  • Use files, folders, applications, and settings in an operating system.
  • Navigate a beginner-friendly Linux environment and command line.
  • Explain how a browser reaches a website using networks and DNS.
  • Understand basic programming ideas and use Git to save work.
  • Use a simple, repeatable approach to troubleshooting.

Course curriculum

Open curated videos, readings & PDFs →

01What Is a Computer?2 LESSONS
Hardware, CPU, memory, storage, input and output, binary ideas, and how software gives instructions to hardware.
02Operating Systems & Files2 LESSONS
Applications, processes, filesystems, users, permissions, and the roles of Windows, macOS, and Linux.
03Linux & the Command Line2 LESSONS
Terminal basics, navigating files, common commands, safe experimentation, and beginner shell concepts.
04How the Internet Works2 LESSONS
Networks, IP addresses, DNS, routers, websites, browsers, HTTP, and a first look at encryption.
05Programs, Git & Troubleshooting2 LESSONS · CAPSTONE
Variables and scripts, version control basics, reading error messages, asking good technical questions, and documenting a small computer setup.

Designed for

Complete beginners, career switchers, and anyone who wants the technical foundations before choosing a specialty.

No assumed experience

Lessons define technical terms and build gradually. Activities use a local computer and free tools wherever possible.

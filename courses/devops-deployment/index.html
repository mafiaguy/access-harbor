What you’ll learn

  • Use Git branches, commits, reviews, and tags in a team workflow.
  • Build a basic continuous integration pipeline.
  • Package and run an application in a container.
  • Understand deployment strategies and safe rollback.
  • Describe infrastructure as code and configuration management.
  • Connect delivery practices to monitoring and operational feedback.

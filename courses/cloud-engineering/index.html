Cloud Engineering
build on solid ground.

Understand the building blocks behind cloud platforms and learn how to design, deploy, and operate useful cloud infrastructure. Start with fundamentals; no production cloud experience required.

BEGINNER FRIENDLY12–16 HOURSCURATED FREE RESOURCES

Explore the course, then work through the lessons and practice activities in one place.

What you’ll learn

  • Explain cloud regions, zones, shared responsibility, and service models.
  • Choose compute, storage, and managed services for simple workloads.
  • Plan virtual networks, routing, DNS, and segmentation.
  • Apply identity, access, encryption, and backup fundamentals.
  • Deploy and observe a small cloud-hosted application.
  • Document architecture, cost assumptions, and operational risks.

Course curriculum

01Cloud Concepts & Shared Responsibility2 LESSONS
Cloud service models, regions and zones, accounts and projects, shared responsibility, and cost basics.
02Compute, Storage & Managed Services2 LESSONS
Virtual machines, object and block storage, managed databases, serverless basics, and workload selection.
03Cloud Networking2 LESSONS
Virtual networks, subnets, routes, security groups, DNS, public and private connectivity, and segmentation.
04Identity, Data & Reliability2 LESSONS
Identity and access, encryption concepts, secrets, backup strategies, availability, and recovery planning.
05Deploy & Operate a Cloud Workload2 LESSONS · CAPSTONE
Deploy a small service, document its architecture and cost assumptions, add logs and monitoring, and write a basic runbook.

Designed for

New cloud learners, developers, systems administrators, and people moving into platform or cloud roles.

Learning approach

Short explanations, official documentation, architecture exercises, and a guided project. No expensive lab account is required for core lessons.
